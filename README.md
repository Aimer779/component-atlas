# 组件图鉴 · Component Atlas

当前从 `laper/`、`cromma-landing/` 提取 15 类组件、23 个变体。参考 React Bits 的目录和索引形式，采用 Google Material 的设计规范与令牌组织方式。

## 运行

在本目录用 PowerShell 执行：

```powershell
node serve.mjs
```

打开 [http://127.0.0.1:5190/](http://127.0.0.1:5190/)。无需安装依赖。ES module 和本地源码读取需要 HTTP 服务，请不要直接双击 `index.html`。

## 查看与复用

- 左侧目录可展开变体；目录项和每个详情都有独立 hash 地址。
- 侧栏的名称进入组件，右侧箭头单独展开变体；筛选和导航保留展开状态。箭头使用固定 32px 点击区与居中 SVG。
- 总览按类别或来源查看；详情有交互预览、重播和源码复制。
- 右上角太阳 / 月亮按钮切换明暗主题，刷新后保留选择；示例沿用来源外观，切换保留其操作状态。
- 来源与源码下拉使用 React Bits Glide Select 的原生适配版：支持滑动高亮、键盘选择、Escape / Tab 关闭和视口边界定位。原始源码与许可保存在 [vendor/react-bits](vendor/react-bits/README.md)。
- 页面、侧栏、源码、菜单和预览共用细圆角滚动条，适配明暗主题；示例依赖中的 `ui/scrollbars.css` 也列入源码下拉。
- `demos/*.html` 是独立样例，对应的 `snapshots/`、`engines/` 和演示模块依赖在源码下拉中列出。
- [design.md](design.md) 记录设计系统，[NOTES.md](NOTES.md) 记录来源、差异和验证边界。
- 每个演示按钮只提供本地交互，不进入原产品流程。
- 新收录共享元素弹层、循环剧本带、滚动弹簧放大和材质提示条。弹层使用已有本地图片演示，不加载视频。
- 源码文件下拉由变体依赖清单生成，字体和图片提供下载链接；普通按钮不加载无用的画布引擎。

## 检查

```powershell
node tools/verify.mjs
```

源码、资产、清单及 16 项回归检查；不替代实际浏览器视觉评审。回归覆盖静态云形、资源释放、依赖完整性、菜单状态、轨道刷新率、弹簧稳定性、隐藏预览恢复、弹层边界、主题恢复、存储受限、跨标签页同步、下拉键盘首字查找和菜单视口边界。另校验五份 React Bits 源文件哈希。实际展开、焦点、清理与视觉检查记录在 NOTES.md。

## 重新提取

`python -B tools/extract.py` 会从相邻两个实验重建 23 个样例并更新快照与来源哈希，**覆盖本图鉴生成的 HTML、快照与引擎适配文件**。常规浏览无需执行。它不修改来源目录；重新提取后执行完整检查并重新评审样例。

`snapshots/` 保留逐字节来源证据；`engines/` 由 `tools/adapt_engines.py` 生成，只调整静态初始化和资源生命周期，原着色器字符串由回归测试核对。不要直接改生成的引擎文件。

当前版本保留完整来源 CSS，便于核对原材质，尚未裁剪为可发布的组件包。原站未声明可再分发许可的设计和代码只在本地学习使用；字体是已有本地资产，当前不重新获取外部素材。

按用户要求，图鉴面向桌面使用，第一版不做手机窄屏适配。

本目录已初始化本地 Git。源码、说明和检查证据纳入版本控制；Python 缓存和临时测试结果忽略。快照关闭 Git 文本换行转换，保护来源哈希。
