# 组件图鉴 · Component Atlas

当前从 `laper/`、`cromma-landing/` 提取 15 类组件、23 个变体。参考 React Bits 的目录和索引形式，采用 Google Material 的设计规范与令牌组织方式。

## 运行

在本目录用 PowerShell 执行：

```powershell
node serve.mjs
```

打开 [http://127.0.0.1:5190/](http://127.0.0.1:5190/)。无需安装依赖。ES module 和本地源码读取需要 HTTP 服务，请不要直接双击 `index.html`。

## 查看与复用

- 设计系统页用侧栏下拉框切换「图鉴外壳 / Laper / Cromma」。下拉框复用已有 Glide Select，支持键盘选择与 Escape。左侧目录定位章节，支持直接地址、前进与后退。色值可复制；字体按实际字号展示；间距与轮廓提供图形样张。材质复用原组件，动效按需播放一次。
- 左侧目录可展开变体；目录项和每个详情都有独立 hash 地址。
- 侧栏的名称进入组件，右侧箭头单独展开变体；筛选和导航保留展开状态。箭头使用固定 32px 点击区与居中 SVG。
- 每个主导航用徽标显示变体数。分组标题使用较粗字重、疏朗字距与组间分隔，区分可点击链接。
- 侧栏顶部的图标分段控件筛选类别，目录与总览同步更新。「全部」恢复总览。图标悬浮或键盘焦点显示中文提示，Escape 关闭；方向键与 Home / End 可切换。总览保留来源筛选。
- 整张卡片可进入详情。详情用带眼睛 / 代码图标的「预览 / 代码」分段控件切换，支持方向键与 Home / End。
- 图鉴界面使用本地 Inter、Noto Sans SC 子集；代码使用 JetBrains Mono。三款采用免费 OFL 1.1，允许非商业使用。来源、完整许可与字符集重建说明见 [字体记录](assets/fonts/SOURCES.md)。组件预览保留原字体。
- 右上角太阳 / 月亮按钮切换明暗主题。新主题从按钮位置以 520ms 圆形铺开，覆盖到左下角。快速再次点击会结束当前过渡，应用最新选择。减少动态效果或浏览器不支持时直接切换；刷新保留选择，示例操作状态保留。
- 来源与源码下拉使用 React Bits Glide Select 的原生适配版：支持滑动高亮、键盘选择、Escape / Tab 关闭和视口边界定位。原始源码与许可保存在 [vendor/react-bits](vendor/react-bits/README.md)。
- 页面、侧栏、源码、菜单和预览共用细圆角滚动条，适配明暗主题；示例依赖中的 `ui/scrollbars.css` 也列入源码下拉。
- 页头与正文共用对齐线；源码菜单以稳定容器定位并等宽展开。复制按钮加载完成后可用，成功在按钮内显示勾选与「已复制」，切换文件会复位。
- 保留术语、参数和来源，删除版本标记、重复计数、预览说明、未填写的个人判断与页脚套话；来源节点定位收进详情的「提取来源」。
- `demos/*.html` 是独立样例，对应的 `runtime/` 样式、`engines/` 和演示模块依赖在源码下拉中列出。`snapshots/` 保存原始证据。
- [design.md](design.md) 记录设计系统，[NOTES.md](NOTES.md) 记录来源、差异和验证边界。
- 每个演示按钮只提供本地交互，不进入原产品流程。
- 新收录共享元素弹层、循环剧本带、滚动弹簧放大和材质提示条。弹层使用已有本地图片演示，不加载视频。
- 源码文件下拉由变体依赖清单生成，字体和图片提供下载链接；普通按钮不加载无用的画布引擎。

## 检查

首次准备检查工具：

```powershell
pnpm install --frozen-lockfile
pnpm exec playwright install --only-shell chromium
pnpm verify
```

`pnpm verify` 执行源码、资产、清单、生成样式校验、Node 回归和浏览器回归。`node tools/verify.mjs` 只执行前五项，不含浏览器检查。工具包都是开发依赖；日常浏览不需要安装它们。

浏览器检查覆盖按需加载、隐藏预览暂停与恢复、手动暂停、重播、弹簧双向收敛、主题与计费状态，以及 23 个变体的完整预览、缩略图和打开状态。计算样式与完整来源快照逐节点对照，包含两个伪元素、材质、圆角、字体与过渡。桌面检查使用 1600×900、1280×720、1024×600。资源检查包含 HTML 内联样式 URL。

这些检查不替代实际视觉评审。无头 Chromium 的工作量指标不能代表笔记本功耗、真实 GPU 帧率或其它浏览器。检查证据与边界记录在 NOTES.md。

## 性能与生成文件

- 总览在预览进入视口附近时加载。预加载不会启动屏幕外动画。移出视口、切到源码或后台标签页时暂停；恢复时保留当前状态。
- 手动暂停的剧本带不会因页面恢复而自动继续。弹簧收敛后停止帧调度，滚动或尺寸变化时恢复。材质提示条的自动关闭计时与预览活动同步。
- HTTP 资源允许存储，每次使用前以内容 ETag 校验。返回总览与重播可复用缓存；修改同尺寸文件后仍能读取新内容。
- `runtime/*.css` 从来源 CSS、现有示例与交互代码生成。保留令牌、预检、伪类分支、keyframes 和动态类。原始样式快照不改。新增示例或交互 class 后执行 `pnpm build:styles`。
- 编辑器图片使用无损 WebP；纸张纹理来自本地文件。来源与许可范围见 [assets/SOURCES.md](assets/SOURCES.md)。
- `node tools/performance-probe.mjs after` 保存工作量与 HTTP 传输证据。不要在优化版本上覆盖已保存的 `before` 记录。

## 重新提取

`python -B tools/extract.py` 会从相邻两个实验重建 23 个样例并更新快照与来源哈希，**覆盖本图鉴生成的 HTML、快照与引擎适配文件**。常规浏览无需执行。它不修改来源目录；重新提取后执行完整检查并重新评审样例。

`snapshots/` 保留逐字节来源证据；`engines/` 由 `tools/adapt_engines.py` 生成，调整静态初始化、暂停与恢复、资源释放。原着色器字符串由回归测试核对。不要直接改生成的引擎文件。

当前版本保留完整来源 CSS 作为证据，运行时加载精简副本。它仍是本地学习图鉴，不是可发布的组件包。原站未声明可再分发许可的设计和代码只在本地学习使用；字体沿用已有本地资产。

按用户要求，图鉴面向桌面使用，第一版不做手机窄屏适配。

本目录已初始化本地 Git。源码、说明和检查证据纳入版本控制；Python 缓存和临时测试结果忽略。快照关闭 Git 文本换行转换，保护来源哈希。
