# 性能优化对抗性评估

日期：2026-10-06。评估者：独立子智能体。

结论：**PASS，限下述已验证范围。**

优化已改变资源加载与运行行为。
评估检查了实际调度与资源释放。
结论不只依据 `data-active` 标签。

## 独立行为证据

- 使用系统 Chrome 的有界面自动化浏览器。
  视口为 1280×720。
  探针同时记录 RAF、interval、ResizeObserver。
  探针也记录 GL 绘制与资源创建、删除。
- 真实近视口加载：剧本带与弹簧的顶部为 790px。
  两者已加载，仍处于屏幕外。
  两者 `active=false`，pending RAF 为 0。
  滚出视口的已加载预览也为 inactive。
- 两种云层、动态图阵与剧本带进入源码面板后，
  在 400ms 内没有新增 RAF 回调或 GL 绘制。
  云层 footer 的 interval 数量降为 0。
  返回预览后，仅恢复一个持续 RAF。
- 子文档模拟隐藏时停止调度。
  父页面再次发送 enable 也不能绕过隐藏条件。
  恢复可见后重新启动单个 RAF。
- 上述四种预览各重播五次。
  旧窗口 pending RAF、interval、存活观察器均为 0。
  每个旧 GL 实例都显式删除其资源：
  2 个 shader、1 个 program、1 个 buffer。
  创建与删除数量逐项相等。
- Toast 显示 1s 后进入源码面板。
  隐藏 5.5s 后仍保留提示。
  恢复 1.2s 后也未提前过期。
  随后按剩余时长退出并释放 field 观察器。
  退出后 pending RAF 为 0。

## 指标与覆盖限制

`performance-before.json` 未包含网络编码字节数。
before 探针启用请求拦截，禁用了 HTTP 缓存。
after 探针未启用该拦截。
decoded response bytes 不是网络传输量。
不能据此声称前后网络提速百分比。
初始预览 15→6 和资源文件大小可直接比较。
最终版本的冷、暖网络指标应单独解释。

真实后台验证未完成。

这次尝试不能证明实际系统后台生命周期。
